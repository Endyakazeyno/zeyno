### 📥 Metodi di Collegamento
Copia e incolla i seguenti comandi nel tuo terminale per installare il bot.

#### 📱 COLLEGAMENTO CON TERMUX
```bash
termux-setup-storage &&
pkg update -y && pkg upgrade -y &&
pkg install -y git nodejs ffmpeg imagemagick &&
git clone https://github.com/Endyakazeyno/zeyno.git &&
cd ~/zeyno &&
yarn install &&
npm start

```

#### 🖥️ COLLEGAMENTO CON LINUX
```bash
sudo apt update && sudo apt upgrade -y && \
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && \
sudo apt install -y nodejs git ffmpeg imagemagick yarn && \
git clone https://github.com/Endyakazeyno/zeyno.git ~/axion-bot && \
cd ~/axion-bot && \
yarn install || npm install && \
npm start

```

#### ♻️ ELIMINA SESSIONI 
```bash
cd ~/zeyno
rm -rf session
npm start

```
